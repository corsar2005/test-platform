# Python Test Lab

Небольшая платформа тестирования на FastAPI и SQLite.

## Возможности

- один правильный ответ;
- несколько правильных ответов;
- письменное задание с текстовым ответом, редактором Python или загрузкой `.py`;
- автоматическая проверка закрытых вопросов;
- сохранение попыток и ответов в SQLite;
- письменные ответы сохраняются для ручной проверки.
- в банке Python хранится по 100 уникальных заданий для каждого из пяти уровней: легкого, среднего, сложного, углубленного и экспертного;
- банк FastAPI содержит по 100 уникальных вопросов каждого из шести уровней, включая уровень «Мастер»;
- в банке aiogram есть по 100 уникальных вопросов пяти уровней сложности по созданию ботов на aiogram 3.x;
- в банках «Многопоточность», «Многопроцессорность» и «Асинхронность» есть по 100 уникальных вопросов каждого из пяти уровней сложности;
- в банках «Генератор» и «Декоратор» есть по 100 уникальных вопросов каждого из пяти уровней сложности;
- в банке «Регулярные выражения» есть по 100 уникальных вопросов каждого из пяти уровней сложности;
- в банке Pandas есть по 100 уникальных вопросов каждого из пяти уровней сложности;
- в банках unittest и pytest есть по 100 уникальных вопросов каждого из пяти уровней сложности;
- в банке «Линтеры» есть по 100 уникальных вопросов каждого из пяти уровней сложности по Ruff, Flake8 и Pylint;
- в банке «Работа с файлами и форматами» есть по 100 уникальных вопросов каждого из пяти уровней сложности: файловый ввод-вывод, pathlib, CSV, JSON, XML, YAML, TOML и безопасная обработка данных;
- в банке «Базы данных» есть по 100 уникальных вопросов каждого из пяти уровней сложности по SQL, PostgreSQL, SQLite и MySQL;
- для каждой попытки случайно выбираются 20 заданий;
- после отправки показываются количество правильных ответов и разбор для самопроверки.
- в отдельной вкладке «Теория» собраны статьи по темам тестов; в конце каждой статьи есть переход к тесту по этой теме.
- во время теста отображается число заданий с ответами и полоса прогресса;
- вкладка «Статистика» хранит прогресс изучения статей и историю попыток с баллами и оценками;
- оценка за попытку рассчитывается по проценту набранных баллов: 5 — от 85%, 4 — от 70%, 3 — от 50%, иначе 2; если есть письменный ответ, оценка предварительная до ручной проверки.
- пользователи регистрируются и входят в аккаунт; имя пользователя обрезается по краям и должно содержать не менее трех символов, email сохраняется в нижнем регистре;
- попытки тестирования сохраняются за конкретным пользователем;
- пароли хранятся в базе только в виде PBKDF2-хэшей.

## Локальный запуск в Windows PowerShell

```powershell
.\.venv\Scripts\Activate.ps1
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
# При необходимости измените SQLITE_DATABASE_PATH в файле .env.
python -m uvicorn main:app --reload
```

Откройте `http://127.0.0.1:8000`.

Параметры конфигурации читаются из переменных окружения. Для локального запуска приложение загружает `.env` из корня проекта; переменные, заданные в окружении Windows, имеют приоритет. По умолчанию SQLite-файл `test_platform.db` находится в корне проекта. Чтобы выбрать другой локальный файл, задайте `SQLITE_DATABASE_PATH` в `.env`; относительные пути разрешаются относительно корня проекта, абсолютные пути тоже поддерживаются. Например, `SQLITE_DATABASE_PATH=data\practice.db` использует файл `data\practice.db` внутри проекта.

Чтобы подключить облачную базу Neon, скопируйте connection string PostgreSQL в `NEON_DATABASE_URL` файла `.env`. Приложение автоматически использует драйвер Psycopg 3 и требует SSL для этого подключения. В PowerShell можно также задать `$env:NEON_DATABASE_URL = "..."` перед запуском. `NEON_DATABASE_URL` имеет приоритет над `DATABASE_URL` и локальной SQLite. При переключении на Neon приложение создаст и заполнит облачную базу; данные из локального SQLite-файла автоматически не копируются.

При заданном `DATABASE_URL` он имеет приоритет над `SQLITE_DATABASE_PATH` и позволяет указать полный URL подключения, в том числе URL SQLite или другой СУБД. PostgreSQL URL без явно заданного драйвера также подключается через Psycopg 3. Для других СУБД установите соответствующий SQLAlchemy-драйвер. Для относительного пути в URL SQLite используйте стандартный синтаксис SQLAlchemy; чтобы путь гарантированно считался от корня проекта, предпочтительнее `SQLITE_DATABASE_PATH`. Храните учётные данные внешней базы в `.env` или в менеджере секретов окружения; файл `.env` исключён из Git.

Приложению не нужен статический `SECRET_KEY`: сессионные токены создаются криптографически стойким генератором случайных чисел, а пароли пользователей хранятся только в виде PBKDF2-хэшей.

## Публикация на GitHub и Render

1. Создайте пустой репозиторий GitHub. В корне проекта выполните команды ниже; перед коммитом проверьте список файлов и убедитесь, что `.env` и SQLite-базы не попали в staged changes.

   ```powershell
   git init
   git add .
   git status --short
   git commit -m "Prepare Python Test Lab for deployment"
   git branch -M main
   git remote add origin https://github.com/<USER>/<REPOSITORY>.git
   git push -u origin main
   ```

   `.gitignore` исключает `.env`, виртуальное окружение, локальные SQLite-базы и кэш; не добавляйте секреты или базу данных вручную.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите настройки из `render.yaml`.
3. При создании сервиса задайте `NEON_DATABASE_URL` значением connection string из Neon. Не сохраняйте URL с паролем в репозитории.
4. Дождитесь успешного деплоя и откройте адрес Render. Проверка состояния доступна по `/health`.

Blueprint задаёт команду сборки/запуска, Python 3.12 и включает `SESSION_COOKIE_SECURE` для HTTPS. При первом запуске приложение создаст таблицы и наполнит Neon вопросами. Локальные данные из `test_platform.db` в Neon автоматически не копируются. Если пароль базы когда-либо публиковался или передавался вне защищённого хранилища, смените его в Neon до публикации и обновите `NEON_DATABASE_URL` в настройках Render и локальном `.env`.

При первом запуске создается файл `test_platform.db` и добавляются банки вопросов Python (500), FastAPI (600), aiogram (500), многопоточности (500), многопроцессорности (500), асинхронности (500), генераторов (500), декораторов (500), регулярных выражений (500), Pandas (500), unittest (500), pytest (500), линтеров (500), работы с файлами и форматами (500) и баз данных (500). В банках Python, aiogram, многопоточности, многопроцессорности, асинхронности, генераторов, декораторов, регулярных выражений, Pandas, unittest, pytest, линтеров, работы с файлами и форматами и баз данных доступно по 100 вопросов на каждый из пяти уровней сложности; в FastAPI есть также уровень «Мастер». Существующая база автоматически дополняется вопросами. После входа пользователь выбирает тему и уровень сложности; для каждой попытки случайно выбираются 20 вопросов. API-документация доступна по адресу `http://127.0.0.1:8000/docs`.

## Запуск тестов

Установите тестовые зависимости и выполните pytest:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты используют отдельную временную SQLite-базу и не подключаются к локальной базе проекта или Neon.

При открытии сайта сначала зарегистрируйте аккаунт или войдите по имени пользователя/email и паролю. Между вкладками «Тесты» и «Теория» можно переключаться после входа; в конце каждой статьи доступен переход к тесту по соответствующей теме. Данные аккаунтов и результаты хранятся в SQLite-файле `test_platform.db`.
